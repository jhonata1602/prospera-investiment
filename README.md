# Prospera Investment

Website institucional premium da Prospera Investment, focado em investimento imobiliário no Reino Unido.

## Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Desenvolvimento local
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Direção do projeto
Leia `PROJECT_BRIEF.md` antes de alterar a experiência, identidade visual ou arquitetura do site.

### Fluxo de trabalho
GitHub = fonte central do código  
Antigravity = desenvolvimento e refinamento técnico
