# Prospera Hero Videos

Esta pasta foi criada para receber os cinco clipes da Hero cinematografica da Prospera Investment.

Arquivos esperados:

1. london-thames-bridge.mp4
2. london-big-ben.mp4
3. london-eye.mp4
4. london-skyline.mp4
5. london-property.mp4

Depois que os MP4 forem adicionados nesta pasta, a Hero podera reproduzir a sequencia cinematografica de Londres.
